## Overview

A Machine Learning Engineer designs, builds, and productionizes ML systems to solve business challenges. This certification learning path provides the advanced knowledge and practical skills required for this role, preparing you to successfully operate and maintain ML systems on Google Cloud.

Through a curated collection of on-demand courses, labs, and skill badges, you will gain real-world, applied experience with Google Cloud technologies. This path focuses on the essential skills needed to design, build, and productionize ML systems.

## Certification Goal

Prepares for the **Google Cloud Professional Machine Learning Engineer (PMLE)** certification exam.

## Activity Descriptions

### 01 - Build a Certification Study Guide: PMLE
Learn how to use NotebookLM to create a personalized study guide for the PMLE certification exam. You'll review NotebookLM features, create a notebook, and use the study guide to practice for the exam.

### 02 - A Tour of Google Cloud Hands-on Labs
Access the Google Cloud console and use basic features: Projects, Resources, IAM Users, Roles, Permissions, and APIs.

### 03 - Introduction to AI and Machine Learning on Google Cloud
Introduces Google Cloud's AI and ML capabilities, covering both generative and predictive AI projects. Explores technologies, products, and tools throughout the data-to-AI lifecycle.

### 04 - Prepare Data for ML APIs on Google Cloud
Skill badge covering: data cleaning with Dataprep by Trifacta, running data pipelines in Dataflow, Apache Spark jobs in Managed Service for Apache Spark, and calling ML APIs (Cloud Natural Language API, Speech-to-Text API, Video Intelligence API).

### 05 - Create ML Models with BigQuery ML
Skill badge covering creating and evaluating machine learning models with BigQuery ML to make data predictions.

### 06 - Engineer Data for Predictive Modeling with BigQuery ML
Skill badge covering: data transformation pipelines to BigQuery using Dataprep by Trifacta, ETL workflows with Cloud Storage, Dataflow, and BigQuery, and building ML models using BigQuery ML.

### 07 - Feature Engineering
Explores Vertex AI Feature Store, improving ML model accuracy, and identifying useful features. Includes labs on feature engineering using BigQuery ML, Keras, and TensorFlow.

### 08 - Build, Train and Deploy ML Models with Keras on Google Cloud *(Deprecated)*
Covers building ML models with TensorFlow and Keras, improving accuracy, and writing ML models for scaled use.

### 09 - Production Machine Learning Systems
Covers production ML system flavors: static, dynamic, and continuous training; static and dynamic inference; batch and online processing. Includes TensorFlow abstraction levels, distributed training options, and custom estimators.

### 10 - Machine Learning Operations (MLOps): Getting Started
Introduces MLOps tools and best practices for deploying, evaluating, monitoring, and operating production ML systems on Google Cloud. Covers continuous improvement and evaluation of deployed models.

### 11 - MLOps with Vertex AI: Manage Features
MLOps tools and best practices with hands-on practice using Vertex AI Feature Store's streaming ingestion at the SDK layer.

### 12 - Introduction to Generative AI
Introductory microlearning course explaining what Generative AI is, how it is used, and how it differs from traditional ML methods. Covers Google tools for Gen AI app development.

### 13 - Introduction to Large Language Models
Explores what LLMs are, their use cases, and how to use prompt tuning to enhance LLM performance. Covers Google tools for Gen AI app development.

### 14 - MLOps for Generative AI
Covers unique challenges faced by MLOps teams when deploying and managing Generative AI models, and how Vertex AI streamlines MLOps processes for Gen AI projects.

### 15 - MLOps with Vertex AI: Model Evaluation
Covers tools, techniques, and best practices for evaluating both generative and predictive AI models. Includes evaluation metrics, methodologies, and their application across different model types.

### 16 - Create Generative AI Apps on Google Cloud
Covers generative AI application development using prompt design and retrieval augmented generation (RAG) to build LLM-powered applications. Includes production-ready architecture for Gen AI apps on Google Cloud.

### 17 - Responsible AI for Developers: Fairness & Bias
Introduces responsible AI concepts and AI principles. Covers techniques to identify fairness and bias and mitigate bias in AI/ML practices using Google Cloud products and open-source tools.

### 18 - Responsible AI for Developers: Interpretability & Transparency
Introduces AI interpretability and transparency concepts. Explores practical methods and tools to achieve interpretability and transparency in data and AI models.

### 19 - Responsible AI for Developers: Privacy & Safety
Introduces AI privacy and safety topics. Explores practical methods and tools to implement AI privacy and safety best practices using Google Cloud products and open-source tools.
