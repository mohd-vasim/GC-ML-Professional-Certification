# 16 - Create Generative AI Apps on Google Cloud

## Type
Course

## URL
https://www.skills.google/course_templates/1120

## Description
Generative AI applications can create new user experiences that were nearly impossible before the invention of large language models (LLMs). In this course, you'll learn about generative AI applications and how you can use prompt design and retrieval augmented generation (RAG) to build powerful applications using LLMs. You'll learn about a production-ready architecture for building Gen AI apps on Google Cloud.

## Key Topics
- Generative AI application development
- Prompt design techniques
- Retrieval Augmented Generation (RAG)
- Building LLM-powered applications on Google Cloud
- Production-ready Gen AI architecture
