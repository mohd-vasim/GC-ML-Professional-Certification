## Key Concepts

### The Module 1 Learning Arc

The module was structured as a deliberate build:
1. **Use Case First** — Coffee on Wheels grounded everything in a real business problem before any technical content was introduced.
2. **Architecture** — Google Cloud's three-layer AI stack (infrastructure → development → applications) set the map for the entire course.
3. **Infrastructure Deep Dive** — Compute, storage, TPUs, and the data-to-AI product workflow made the foundation layer concrete.
4. **Model Fundamentals** — Supervised vs. unsupervised, classification vs. regression — the vocabulary needed to make model choices.
5. **BigQuery ML** — Applied all the theory: picked a model, trained it, evaluated it, predicted with it, all in SQL.
6. **Hands-on Lab** — Reinforced BigQuery ML with real e-commerce data and Gemini Code Assist.

### Key Terms to Anchor

The lesson asks you to identify three key terms you learned. The instructor's list includes: **Predictive AI, Generative AI, Data to AI, BigQuery, Vertex AI, BigQuery ML**. These are the spine of the course.
